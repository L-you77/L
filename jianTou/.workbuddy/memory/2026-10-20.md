## 18:55 无限跑酷修正：金币位置 / ↓ 瞬移 / 强化点 / 生命显示
- **金币全堆在地图开头的根因**：`Attach()` 里是 `AddChild` 之后才设 `GlobalPosition`，
  而 `Coin._Ready()` 会 `_basePosition = Position`（当上下浮动的基准），于是基准被记成 (0,0)，
  每帧 `_Process` 又把坐标拉回 (0,0)。**改成先 `node2D.Position = position` 再 AddChild**。
  （以后往关卡里动态生成 Coin 都要遵守：先摆坐标再入树。）
- **↓ 向下瞬移**（`Player` 新增 `EnableDownTeleport / DownTeleportDistance(24) / DownTeleportCooldown(0.35)`）：
  `Input.IsActionJustPressed("Down")` + `TestMove(GlobalTransform, (0,dist))` 探路，
  没被挡就 `GlobalPosition +=`。因为脚下有地面时 TestMove 返回 true，**站在地上按 ↓ 不会掉进地里，只会蹲下**；
  在空中按 ↓ 才会瞬移下降。
- **强化点**：跑酷里每块有 `CoinSpeChance(0.12)` 概率刷一个 `coin_spe.tscn`；
  捡到 → `Player.UpgradeChargeChanged` → `EndlessRunner` 自己实例化 `upgrade_panel.tscn` 弹三选一
  （暂停着选，选完继续跑），选完才扣次数；关掉不选会把次数退回去（`_refunding` 标志防递归）。
- **生命显示**：去掉 `MaxHealth = 1`（用默认 3），RunnerHud 加 `HealthLabel`（左上角"生命 3/3"），
  订阅 `Player.HealthChanged`。RunnerHud 的 layer 从 20 改成 **8**（低于强化面板的 10、高于触屏 UI 的 5）。
