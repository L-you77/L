## 修 warn 白底 & 眼睛期间不闪红（20:54）
- **根因 1**：`ps/player/warn.png` **没有 alpha 通道**（白底 83% + 黑色感叹号），直接当 Sprite 用就是一个白方块；
  用户又把 `Warn` 节点拖到了角色正中间（`position ≈ (0,0)`）→ 白方块把箭头贴图整个盖住，"之前那张图"看不见了。
  修法：新增 `shader/white_key.gdshader`（近白像素 `discard`），在 player.tscn 里用 `ShaderMaterial_warn` 挂到 Warn 节点上。
  **坑**：shader 里绝对不要写 `COLOR = tex` —— 会覆盖节点自身的 modulate，而 Warn 的闪烁正是靠 modulate 的 alpha。
  只 discard、不写 COLOR，默认 COLOR（vertex color × texture）就保留了 modulate。
- **根因 2**：`Write` 白块盖在 `AnimatedSprite2D` 上，而受伤闪红只染 `_sprite.Modulate` → 被白块挡住，看起来"没闪红"。
  修法：`Player.UpdateSpriteTint()` 改成染**玩家根节点**的 `Modulate`（CanvasItem.Modulate 会向下叠加），
  这样箭头、白块、眼睛会一起变红，无敌帧闪烁也一起。
- 同类提醒：以后凡是"覆盖在角色上方的贴图"，染色/闪烁都走根节点 Modulate，别只染 AnimatedSprite2D。
- 20:59 用户澄清："不显示之前的那张图" = `AnimatedSprite2D` 里的箭头图不显示了（白底方块盖住所致，已由 white_key shader 解决）。
  但这句话也可能是在要求"warn 期间就该藏掉箭头"，两种解读相反 →
  给 `IdleWatcher` 加了开关 `HideArrowDuringWarn`（默认 false = 感叹号叠在箭头上、箭头可见；
  打开 = 感叹号替代角色），`HideAll()` 里统一把箭头恢复可见。
- **21:04 更正**：用户要的正是"warn 期间把 AnimatedSprite2D 设为不可见"，白底方块是**故意**要的（不是 bug）。
  → 撤掉 `white_key.gdshader`（连同 ShaderMaterial 和 shader/ 目录一起删了，无残留引用）；
  → `HideArrowDuringWarn` 默认改成 **true**。
  现在流程：静止 10s → 隐藏箭头 + 白块顶上的感叹号顶替角色 3s → 换 `Write` 白块 + 眼睛（箭头继续隐藏）。
  因为 warn 白块和 Write 白块都是 6×6（scale 0.06 / 100px 图），warn→eye 的切换是"白块接白块"，很自然。
